# Creative-Problem-Solving
ML-based Seoul commercial saturation risk prediction with public data and explainable LLM insights.

## 프로젝트 개요

자영업 창업에서는 상권의 유동인구나 매출 규모만큼이나 동일 업종의 과밀도, 최근 개업/폐업 흐름, 임대 부담, 점포당 매출 변화가 중요합니다. 이 프로젝트는 서울시 공공데이터를 활용하여 상권-업종 단위의 과밀 위험도를 예측하고, 지도와 설명 문장으로 결과를 제공합니다.

핵심 목표는 다음과 같습니다.

- 최근 5년간 상권 데이터를 기반으로 다음 분기 폐업률을 예측
- 점포 수, 개업 수, 폐업 수, 매출, 유동인구, 직장인구, 임대료 지표를 종합 분석
- 예측 결과를 `low`, `medium`, `high` 위험 등급으로 변환
- 지도 기반으로 상권별 위험도를 시각화
- LLM이 모델 결과와 근거 데이터를 바탕으로 사용자 친화적인 설명 생성

## 문제 정의

본 프로젝트는 서울시 상권과 업종 조합에 대해 다음 분기의 폐업률을 예측하는 회귀 문제로 정의합니다.

```text
입력: 상권, 업종, 점포 수, 개업/폐업 수, 매출, 유동인구, 직장인구, 임대료 지표 등
출력: 다음 분기 폐업률(next_closure_rate)
파생 출력: 과밀 위험 점수(risk_score), 위험 등급(low / medium / high)
```

## 모델링 흐름

1. 최근 5년간 분기별 상권 데이터를 수집합니다.
2. 기준 분기, 상권 코드, 업종 코드를 기준으로 데이터를 병합합니다.
3. 결측치 처리, 이상치 확인, 업종명 통일 등 전처리를 수행합니다.
4. 최근 4분기 폐업률 평균, 개업 수 합계, 폐업 수 합계, 매출 증가율, 점포 증가율 등의 파생변수를 생성합니다.
5. 선형회귀를 baseline으로 사용하고, Random Forest와 Gradient Boosting 모델을 비교합니다.
6. MAE, RMSE, R2를 기준으로 모델 성능을 평가합니다.
7. 최종 예측값을 바탕으로 과밀 위험 점수를 계산합니다.
8. 지도와 LLM 설명용 데이터로 결과를 제공합니다.

## 주요 피처

- `store_count`: 현재 점포 수
- `open_count`: 해당 분기 개업 수
- `close_count`: 해당 분기 폐업 수
- `closure_rate`: 현재 폐업률
- `sales_total`: 추정 매출
- `floating_population`: 유동인구
- `resident_population`: 주거인구
- `worker_population`: 직장인구
- `avg_rent`: 임대료 또는 임대료 대체 지표
- `sales_per_store`: 점포당 매출
- `floating_per_store`: 점포당 유동인구
- `closure_rate_4q_avg`: 최근 4분기 평균 폐업률
- `sales_growth_4q`: 최근 4분기 매출 증가율
- `store_growth_4q`: 최근 4분기 점포 증가율

## LLM 결합 방식

LLM은 예측값을 직접 생성하지 않습니다. 숫자 계산과 위험도 판단은 머신러닝 모델이 수행하고, LLM은 모델 결과와 근거 데이터를 사용자에게 이해하기 쉬운 문장으로 설명하는 역할을 합니다.

예시 설명:

```text
강남역 커피전문점 업종은 최근 1년간 개업 수보다 폐업 수가 많고,
점포 수가 빠르게 증가하는 반면 점포당 매출 개선 폭은 제한적입니다.
따라서 신규 진입 시 경쟁 강도가 높은 상권으로 해석됩니다.
```

## 기대 효과

이 프로젝트는 예비 창업자가 단순히 "유동인구가 많은 곳"을 선택하는 것이 아니라, 동일 업종의 경쟁 강도와 폐업 흐름까지 고려하여 입지를 판단할 수 있도록 돕습니다. 또한 공공데이터 기반으로 분석 과정을 재현할 수 있으며, 지도와 LLM 설명을 통해 비전문가도 결과를 쉽게 이해할 수 있습니다.

## 한계 및 향후 개선 방향

- 실제 임대료 데이터는 상권 단위로 완전하게 확보하기 어려울 수 있습니다.
- 폐업 원인은 과밀도 외에도 경기 상황, 정책, 업종 트렌드 등 다양한 요인의 영향을 받습니다.
- 향후 지하철 승하차 인원, 생활인구, 상권별 임대료 데이터를 추가하여 예측 성능을 개선할 수 있습니다.
- SHAP 기반 모델 해석을 추가하면 위험도 산정 근거를 더 정교하게 설명할 수 있습니다.
